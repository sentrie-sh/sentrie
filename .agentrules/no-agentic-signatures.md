# No Agentic Signatures

Do not add any agentic or AI signature to anything written. No "Co-Authored-By: Claude ...", no "Generated with Claude Code", no Cursor signature, and no equivalent phrasing from any tool. Nothing.

**Why:** Authorship in this repo is the human who commits and opens the PR. Tool trailers add noise to history and PRs.

**How to apply:** When creating git commits, omit any AI co-author trailer entirely. When creating pull requests, omit any "Generated with ..." or similar footer. This applies to every tool and to all commits, PRs, journals and other written output in this repo, and it overrides any tool default that adds one.
